PDF Splitter



PDF Splitter is a fast, lightweight, and highly secure web tool for extracting and splitting PDF pages. 



I built this tool because I was tasked with naming and dating tens of thousands of staff records for a company during a 6-month contract, and it is the sole reason I managed to finish the project on time. It saved me countless headaches, and I hope it does the same for you.



Unlike traditional PDF tools that force you to upload sensitive documents to a third-party server, this tool processes everything locally in your browser's RAM. Files never leave your device, no network requests are made, and no data is written to hidden temporary folders.



Key Features



100% Client-Side: Powered by local, workerless builds of PDF.js and PDF-Lib.

GDPR \& Privacy Safe: Ideal for legal, medical, and HR professionals handling confidential files.

Volatile Memory Only: PDFs are held strictly in RAM and vanish the moment the tab is closed.

Direct Binary Downloads: Outputs directly to your local file system, bypassing browser cache and `AppData\\Temp` folders for maximum security.
